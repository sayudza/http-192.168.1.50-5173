# DarsFlow — dars jadvali MVP

Maktab va kollejlar uchun o‘zbek tilidagi haftalik dars jadvali tuzuvchi kichik web-ilova.

## Ishga tushirish

```bash
npm install
npm run dev
```

Terminalda chiqqan `http://localhost:5173/` manzilini brauzerda oching.

## Imkoniyatlar

- Guruhlar, fanlar, o‘qituvchilar va xonalarni qo‘shish/o‘chirish
- Hafta kunlari va dars boshlanish vaqtlarini sozlash
- O‘qituvchi va xona bandligini tekshiradigan qoidaviy jadval yaratish
- Haftalik ko‘rinish, CSV yuklab olish va chop etish
- Ma’lumotlarni brauzerning localStorage xotirasida saqlash

Jadval tuzish hozircha mahalliy algoritm orqali ishlaydi; pulli AI API talab qilinmaydi.

## Build

```bash
npm run build
```
